# Copy Frame Privacy Policy

Copy Frame does not collect, sell, share, or transmit personal data.

The extension runs locally in the user's browser. It may read the current webpage's DOM only when the user actively starts inspection mode, so it can highlight and lock a page area and generate a positioning description that the user may choose to copy.

Copy Frame stores only the user's custom shortcut setting in the browser's local extension storage. This setting is kept locally and is not uploaded to any server.

Copy Frame does not use remote code, analytics, tracking, advertising, or third-party data services.
