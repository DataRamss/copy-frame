# 物料目录说明

这个目录专门存放和插件运行本身无关的内容，避免和源码、构建脚本、发布文件混在一起。

## 当前内容

- `copy-frame-公众号.md`：公众号文案
- `copy-frame-小红书.md`：小红书文案
- `.codex/skills/`：写作或辅助流程用到的技能文件

## 放置原则

适合放进 `物料/` 的内容包括：

- 宣传文案
- 社媒素材
- 产品介绍草稿
- 运营说明
- 写作辅助配置
- 与插件功能实现无直接关系的参考资料

不建议放进 `物料/` 的内容包括：

- `src/` 里的插件源码
- `build.mjs` 这类构建脚本
- `package.json`、`tsconfig.json` 这类工程配置
- `logo.png` 这类插件运行或打包会直接引用的资源
- `dist/` 里的扩展产物

这样整理后，项目根目录会更清楚：插件相关内容留在主工程里，非插件内容统一收纳到这里。
