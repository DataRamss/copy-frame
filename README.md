# Copy Frame

Copy Frame 可以帮你在浏览器中快速高亮并锁定目标区域，一键复制适合发给 AI 的页面定位描述和当前页面链接，让你更准确地表达“我要改这里”。

如果你正在用 AI 开发网页、调试前端界面，或者使用 HTML 制作 PPT，Copy Frame 都很适合你。

## 安装

Copy Frame 已上线 Chrome 应用商店。你可以在商店搜索 `Copy Frame`，或者直接打开下面的链接：

**[前往 Chrome 应用商店安装 Copy Frame](https://chromewebstore.google.com/detail/copy-frame/hcikfcfccmpahpdofmalkakdkinalhgo)**

安装完成后，建议将 Copy Frame 固定到 Chrome 工具栏，点击图标即可使用。

> 如需在本地 HTML 或 `file://` 页面中使用，请在扩展详情页开启“允许访问文件网址”，然后刷新页面。这是 Chrome 的安全限制，插件无法自动开启。

## 适用场景

- 告诉 AI 修改某个按钮、输入框、卡片、弹窗或区域
- 快速定位页面中的 DOM 元素并复制稳定描述
- 使用 AI 开发网页、调试前端界面或制作 HTML PPT
- 辅助联调、页面改版沟通和测试说明

## 主要能力

- 点击 Chrome 工具栏图标，开启检查模式并显示启动提示；提示右侧的设置图标可打开快捷键设置面板
- 鼠标移动时高亮当前可选中的 DOM 元素
- 点击页面元素后锁定选区
- 根据 `data-testid`、`name`、`aria-label`、`id`、类名、文本等信息生成友好的元素名称
- 自动尝试生成更稳定的定位选择器
- 一键复制包含当前页面链接、元素名称和定位选择器的描述文本
- 锁定后可通过键盘在同级、父级、子级元素之间快速切换
- 支持撤销到上一次锁定的选区

## 示例

```text
页面：<https://example.com/login>
[登录页] 登录按钮 :: button[data-testid="login-button"]
```

如果目标元素名称过于泛化，插件会自动补充父级上下文，帮助 AI 更准确理解位置。

## 使用流程

1. 点击 Copy Frame 图标，进入检查模式并查看右下角启动提示
2. 将鼠标移动到目标区域，查看高亮框和名称提示
3. 点击页面中的目标元素，锁定选区
4. 点击高亮框右上角的 `Copy` 按钮，或使用快捷键复制描述
5. 将复制结果粘贴到 AI 对话中，再补充你的修改目标或参考说明

## 快捷键

启动快捷键默认为 `Alt + C`，可在设置面板中修改。下面快捷键需要先锁定页面元素后使用。

| 作用 | 快捷键 |
| --- | --- |
| 复制 | `Ctrl + C` / `Cmd + C` |
| 撤销 | `Ctrl + Z` / `Cmd + Z` |
| 同级切换 | `Tab` / `Shift + Tab` |
| 父子级切换 | `Enter` / `Shift + Enter` |
| 退出锁定 | `Esc` |

点击工具栏图标开启插件时，会显示右下角启动提示。需要调整快捷键时，点击提示右侧的设置图标打开设置面板；关闭面板后仍可继续选择页面元素。

## 开发者本地调试

普通用户请直接从 Chrome 应用商店安装。只有参与开发或调试源码时，才需要执行以下步骤：

```bash
npm install
npm run typecheck
npm run build
```

构建完成后，打开 `chrome://extensions/`，启用“开发者模式”，点击“加载已解压的扩展程序”，选择项目下的 `dist/` 目录。

## 目录说明

- `src/`：插件核心源码，仅保留和扩展功能直接相关的文件
- `dist/`：打包后的可加载目录

## 使用建议

- 优先选择带有 `data-testid`、`name`、`aria-label` 或 `id` 的元素
- 如果选区太大，可按 `Enter` 进入更细一层
- 如果选区太小，可按 `Shift + Enter` 回到父级
- 如果同级有多个相似元素，可用 `Tab` / `Shift + Tab` 快速切换
- 复制后建议补一句目标说明，例如“请把这里改成圆角按钮”

## 当前限制

- 当前主要面向 DOM 元素定位，不适合识别纯画布内容
- `canvas` 区域暂不支持稳定命名
- 一些浏览器受限页面或特殊跨域页面，可能无法正常注入或工作
- 生成结果以“稳定定位 + 友好命名”为主，不等同于完整视觉截图理解

## 产品理念

Copy Frame 不打算成为一个大而全的重型工具。它希望保持“打开即用、用完即走”的状态：不打扰页面，不占用界面，也不把简单问题复杂化。

操作设计尽量贴近下意识动作，例如使用 `Tab` 切换同级元素，使用 `Enter` 进入更具体的子级，配合 `Shift` 反向返回。未来会优先打磨这些核心体验，而不是不断堆叠与定位目标无关的功能。
